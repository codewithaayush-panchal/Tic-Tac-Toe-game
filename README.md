I have created a basic tic tac toc game in java.

It was very easy to write the code and winning algorithm after every move.

This is a simple game made with only java and there is no UI/GUI in the game.

You would have to play after telling the co-ordinates of where you want to play your next move.

This is game written in java with the help of very basic functionalities of java like if-else condition, loops and function.

You can execute this code by just copying it and pasting it in you IDE and you should have JDK to run the program in you local, other wise you can run it on browser using website like programiz, etc.
